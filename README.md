# ESP32 Sensor Labs

**CODEPLANT ESP32 Sensor Labs**는 ESP32와 MicroPython을 활용해 센서, 액추에이터, 디스플레이 모듈을 직접 연결하고 제어해보는 실습형 교육 자료입니다.

이 저장소는 CODEPLANT의 ESP32 강의 영상과 연계하여 사용할 수 있도록 구성되어 있으며, 단순히 코드를 실행하는 것을 넘어 **센서값을 읽고 → 조건을 판단하고 → 출력 장치를 제어하는 피지컬 컴퓨팅 흐름**을 익히는 데 목적이 있습니다.

> 상상을 현실로 만드는 교육, CODEPLANT
> 직접 만들며 배우는 SW·HW 융합 코딩 실습

## Repository Overview

이 저장소는 ESP32 기반 센서 실습을 단계별로 학습할 수 있도록 구성되어 있습니다.

각 실습 폴더에는 다음 자료가 포함됩니다.

```text
각 실습 폴더/
├─ README.md 또는 readme.md     # 실습 설명, 준비물, 배선, 코드 흐름
└─ code/                       # MicroPython 예제 코드
```

학습자는 각 폴더의 README를 따라 배선을 구성하고, `code` 폴더 안의 예제 파일을 Thonny에서 실행하면서 센서와 액추에이터의 동작을 확인할 수 있습니다.

## Required Environment

### Hardware

기본적으로 다음 환경을 기준으로 실습합니다.

* ESP32 DevKit 보드
* USB 케이블
* 브레드보드
* 점퍼선
* 각 실습별 센서 및 모듈
* 필요 시 외부 전원
* PC 또는 노트북

### Software

* MicroPython 펌웨어가 설치된 ESP32
* Thonny IDE
* Python 기반 시리얼 실행 환경

Thonny에서 ESP32를 사용하는 경우 다음 순서로 진행합니다.

1. ESP32를 USB 케이블로 PC에 연결합니다.
2. Thonny를 실행합니다.
3. 인터프리터를 `MicroPython (ESP32)`로 설정합니다.
4. 포트를 선택합니다.
5. 실습 코드를 열고 실행합니다.
6. Shell 창에서 센서값과 출력 결과를 확인합니다.

## How to Study

이 저장소는 다음 순서로 학습하는 것을 권장합니다.

### 1. 단일 부품 동작 확인

먼저 센서 또는 모듈 하나만 연결하여 정상적으로 동작하는지 확인합니다.

예시:

```text
초음파 센서 → 거리값 출력
PIR 센서 → 움직임 감지 출력
조도 센서 → 밝기값 출력
```

### 2. 센서값을 조건으로 판단

측정값을 단순 출력하는 것에서 끝내지 않고, 조건문을 사용해 의미 있는 판단을 만듭니다.

예시:

```python
if distance < 15:
    print("가까움")
else:
    print("멀리 있음")
```

### 3. 출력 장치와 연결

센서값에 따라 LED, 부저, 모터, 릴레이, 워터펌프 등을 제어합니다.

예시:

```text
거리가 가까우면 → 부저 울림
어두워지면 → LED 켜짐
물이 부족하면 → 워터펌프 작동
움직임이 감지되면 → 경고 출력
```

### 4. 미니 프로젝트로 확장

여러 센서와 액추에이터를 조합하여 하나의 시스템을 구성합니다.

예시:

* 스마트 조명
* 침입 감지 경보 시스템
* 자동 급수 시스템
* 수위 감지 알림 장치
* 센서값 OLED 표시 장치
* 스마트팜 기초 제어 시스템

```text
센서값 측정 → 데이터 변환 → OLED/LCD 표시
```

## Important Safety Notes

ESP32와 외부 모듈을 사용할 때는 다음 사항을 반드시 확인해야 합니다.

### 1. ESP32 입력 전압 주의

ESP32의 GPIO 입력은 기본적으로 **3.3V 기준**입니다.
일부 센서 모듈은 출력 신호가 5V일 수 있으므로, 필요한 경우 저항 분압 또는 레벨시프터를 사용해야 합니다.

특히 다음 모듈은 주의가 필요합니다.

* HC-SR04 초음파 센서의 ECHO 핀
* 일부 릴레이 모듈의 입력 신호
* 일부 5V 센서 모듈의 디지털 출력

### 2. 공통 GND 필수

외부 전원, 모터드라이버, 릴레이, 워터펌프 등을 사용할 때는 ESP32와 모듈의 GND를 공통으로 연결해야 합니다.

```text
ESP32 GND
외부 전원 GND
모듈 GND
```

위 기준점이 같아야 신호가 정상적으로 전달됩니다.

### 3. 모터와 펌프는 외부 전원 권장

모터, 워터펌프, 릴레이 구동 장치는 ESP32 보드의 3.3V 핀에서 직접 구동하지 않는 것을 권장합니다.

* 모터는 순간 전류가 큽니다.
* 펌프는 구동 시 전압 강하가 발생할 수 있습니다.
* ESP32가 리셋되거나 불안정해질 수 있습니다.

따라서 모터드라이버, 릴레이 모듈, 외부 전원을 함께 사용해야 합니다.

### 4. AC 전원 사용 금지 또는 강사 지도 필수

초급 실습에서는 220V AC 전원 제어를 권장하지 않습니다.
릴레이 실습은 저전압 DC 장치 위주로 진행하고, AC 전원 제어는 반드시 전문가 또는 강사의 지도 아래 진행해야 합니다.

## Code Style

이 저장소의 코드는 교육용으로 이해하기 쉽도록 작성하는 것을 우선합니다.

기본 원칙은 다음과 같습니다.

* 한 파일에서 하나의 핵심 개념을 실습합니다.
* 핀 번호는 코드 상단에 모아둡니다.
* 센서값은 Shell에 출력하여 바로 확인할 수 있게 합니다.
* 복잡한 구조보다 학습자가 읽기 쉬운 구조를 우선합니다.
* 실습이 끝난 뒤 프로젝트형 코드로 확장할 수 있도록 구성합니다.

예시 구조:

```python
from machine import Pin
import time

# 1. 핀 설정
SENSOR_PIN = 26

# 2. 객체 생성
sensor = Pin(SENSOR_PIN, Pin.IN)

# 3. 반복 실행
while True:
    value = sensor.value()
    print(value)
    time.sleep(0.2)
```

## Troubleshooting

| 문제 상황             | 확인할 내용                                |
| ----------------- | ------------------------------------- |
| ESP32가 연결되지 않음    | USB 케이블, 포트, 드라이버, Thonny 인터프리터 설정 확인 |
| 센서값이 계속 0으로 나옴    | VCC/GND/SIG 배선, 핀 번호, 공통 GND 확인       |
| 값이 심하게 튐          | 센서 방향, 주변 환경, 평균 필터 적용 여부 확인          |
| 모터가 돌지 않음         | 외부 전원, 모터드라이버 배선, 공통 GND, PWM 핀 확인    |
| ESP32가 리셋됨        | 모터/펌프 전류 부족, 외부 전원 분리, 전원 안정성 확인      |
| OLED/LCD가 출력되지 않음 | I2C 주소, SDA/SCL 핀, 전원, 라이브러리 파일 확인    |
| 릴레이가 동작하지 않음      | 입력 신호 전압, VCC/JD-VCC 구조, 모듈 타입 확인     |

이 저장소는 ESP32를 처음 다루는 학습자가 센서와 액추에이터를 직접 연결하고, 코드를 실행하며, 실제 동작을 눈으로 확인할 수 있도록 구성된 실습 자료입니다.

CODEPLANT는 학습자가 단순히 코드를 따라 치는 것을 넘어, 직접 만들고 실험하며 자신의 아이디어를 현실로 구현하는 경험을 중요하게 생각합니다.

센서값을 읽고, 조건을 판단하고, 장치를 제어하는 경험은 모든 피지컬 컴퓨팅 프로젝트의 출발점입니다.

이 저장소가 ESP32 기반 메이킹 수업과 프로젝트 학습의 좋은 시작점이 되기를 바랍니다.
